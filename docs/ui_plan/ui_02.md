# UI-02 — Main Layout & Workspace Architecture

## 1. Objective

Hoàn thiện cấu trúc giao diện chính của Java SQL IDE.

Tập trung vào:

* Main Workspace Layout.
* Object Explorer.
* Editor Workspace.
* Editor Tab Bar.
* Results Panel.
* Panel Resizing.
* Panel Collapse / Expand.
* Layout State Management.

Tham khảo bố cục và hành vi từ LLTool, đồng thời áp dụng các nguyên tắc thiết kế của DataGrip và VS Code.

Không yêu cầu chuyển đổi toàn bộ giao diện LLTool.

## 2. Prerequisites

UI-01 đã hoàn thành:

* Main Window.
* Custom Title Bar.
* Menu Bar.
* Main Toolbar.
* Status Bar.
* Dark Theme cơ bản.

Trước khi triển khai, Agent phải đọc lại code UI-01 để bảo đảm tương thích.

Không tự ý viết lại MainWindow nếu không có lý do kiến trúc rõ ràng.

## 3. Main Layout Architecture

Sử dụng cấu trúc tổng thể:

```text
MainWindow
│
├── TitleBar
│
├── MenuBar
│
├── MainToolbar
│
├── MainWorkspace
│   │
│   ├── LeftPanel
│   │   └── ObjectExplorer
│   │
│   └── CenterWorkspace
│       │
│       ├── EditorWorkspace
│       │   ├── EditorTabBar
│       │   ├── EditorContent
│       │   └── EditorStatusBar
│       │
│       └── ResultsPanel
│           ├── ResultsTabBar
│           └── ResultsContent
│
└── StatusBar
```

Sử dụng JavaFX layout containers phù hợp:

* BorderPane.
* SplitPane.
* VBox.
* HBox.
* StackPane.
* TabPane hoặc custom tab component.

Không bắt buộc sử dụng đúng một loại container cho tất cả khu vực.

## 4. Object Explorer

### 4.1 Header

Bao gồm:

* Object Explorer title.
* Refresh button.
* Collapse button.
* More actions button.

### 4.2 Search

Có ô tìm kiếm đối tượng.

Yêu cầu:

* Có placeholder.
* Có nút clear.
* Có thể nhập và xóa nội dung.
* Chưa cần tìm kiếm database thực tế.

### 4.3 Connection Tree

Sử dụng TreeView với dữ liệu giả lập:

```text
Connections
│
├── SQL Server - Development
│   ├── Databases
│   │   ├── Database_A
│   │   │   ├── Tables
│   │   │   ├── Views
│   │   │   ├── Procedures
│   │   │   └── Functions
│   │   └── Database_B
│   │
│   └── Security
│
└── PostgreSQL - Local
    ├── Databases
    │   └── Database_C
    │       ├── Schemas
    │       │   └── public
    │       │       ├── Tables
    │       │       ├── Views
    │       │       └── Functions
    │       └── Extensions
    │
    └── Roles
```

Yêu cầu:

* Expand / Collapse.
* Icon phân biệt loại đối tượng.
* Context menu khi click chuột phải.
* Selection state.
* Có thể thêm node giả lập bằng code.
* Không kết nối database.

### 4.4 Explorer Interaction

Triển khai:

* Chọn connection.
* Chọn database.
* Mở rộng node.
* Thu gọn node.
* Refresh UI.
* Context menu cơ bản.

Chỉ cần mô phỏng hành vi.

## 5. Editor Workspace

### 5.1 Editor Tab Bar

Tạo hệ thống tab riêng, không phụ thuộc hoàn toàn vào TabPane mặc định nếu không đáp ứng được thiết kế.

Mỗi tab cần hỗ trợ:

* Tab title.
* File type icon.
* Active state.
* Dirty state.
* Close button.
* Context menu.

Các hành vi:

* New Tab.
* Switch Tab.
* Close Tab.
* Close Others.
* Close All.
* Reorder Tab nếu khả thi.

Chưa cần quản lý nội dung SQL thực tế.

### 5.2 Editor Content

Tạo vùng nội dung trung tâm.

Yêu cầu:

* Hiển thị placeholder khi chưa có tab.
* Khi tạo tab mới, hiển thị một editor placeholder.
* Có khả năng thay thế placeholder bằng Monaco trong UI-03.
* Không thiết kế layout phụ thuộc vào TextArea hoặc TextField.

Lưu ý: Editor Content phải được tách thành component độc lập.

### 5.3 Editor Status Bar

Tạo thanh thông tin phía dưới Editor:

* Line.
* Column.
* Encoding.
* Line Ending.
* Language Mode.

Sử dụng dữ liệu giả lập.

## 6. Results Panel

### 6.1 Panel Layout

Results Panel nằm phía dưới Editor Workspace.

Có thể thay đổi chiều cao bằng splitter.

### 6.2 Result Tabs

Tạo các tab:

* Results.
* Messages.
* Execution Plan.

Mỗi tab có vùng nội dung riêng.

### 6.3 Results Placeholder

Tạo giao diện bảng dữ liệu giả lập:

| ID | Name      | Status   | Created Date |
| -- | --------- | -------- | ------------ |
| 1  | Example A | Active   | 2026-01-01   |
| 2  | Example B | Active   | 2026-01-02   |
| 3  | Example C | Inactive | 2026-01-03   |

Sử dụng JavaFX TableView.

Mục tiêu chỉ là kiểm tra khả năng hiển thị và bố cục.

Chưa triển khai:

* Database result binding.
* Pagination thực tế.
* Query execution.
* Export.
* Virtualized data loading.

### 6.4 Messages

Hiển thị nội dung mẫu:

```text
Query executed successfully.
3 rows returned.
Execution time: 125 ms.
```

### 6.5 Execution Plan

Tạo placeholder để sau này tích hợp execution plan viewer.

## 7. Splitter & Panel Management

Đây là phần quan trọng nhất của UI-02.

### 7.1 Horizontal Splitter

Cho phép resize giữa:

* Object Explorer.
* Center Workspace.

### 7.2 Vertical Splitter

Cho phép resize giữa:

* Editor Workspace.
* Results Panel.

### 7.3 Collapse / Expand

Hỗ trợ:

* Collapse Object Explorer.
* Expand Object Explorer.
* Collapse Results Panel.
* Expand Results Panel.

Khi collapse:

* Không được làm hỏng bố cục tổng thể.
* Các vùng còn lại phải tự động mở rộng.
* Có nút hoặc cơ chế khôi phục panel.

### 7.4 Default Dimensions

Thiết lập kích thước mặc định ban đầu:

| Component         |                Default |
| ----------------- | ---------------------: |
| Object Explorer   |                 260 px |
| Results Panel     |                 220 px |
| Editor Workspace  | Phần diện tích còn lại |
| Editor Tab Bar    |                  36 px |
| Editor Status Bar |                  24 px |
| Results Tab Bar   |                  34 px |

Các giá trị trên là điểm xuất phát, không phải kích thước cố định.

Yêu cầu:

* Có min width / min height hợp lý.
* Không để panel bị thu nhỏ đến mức không sử dụng được.
* Có thể thay đổi kích thước bằng thao tác kéo.
* Không hard-code kích thước ở nhiều vị trí khác nhau.

## 8. Layout State Management

Tạo cơ chế quản lý trạng thái giao diện.

Lưu các thông tin:

* Explorer width.
* Results height.
* Explorer visibility.
* Results visibility.
* Active editor tab.
* Active result tab.

Yêu cầu:

* Có thể lưu trạng thái hiện tại.
* Có thể khôi phục trạng thái khi mở ứng dụng.
* Tách LayoutState khỏi MainWindow.
* Không lưu trạng thái giao diện trực tiếp trong từng component.

Có thể sử dụng Java Preferences hoặc cơ chế cấu hình hiện tại của project.

Chưa cần xây dựng Settings UI.

## 10. Design Requirements

* Đồng bộ với UI-01.
* Dark Theme.
* Modern desktop IDE.
* Tối ưu không gian làm việc.
* Khoảng cách và kích thước component nhất quán.
* Có hover state.
* Có active state.
* Có focus state.
* Có tooltip cho icon button.
* Không sử dụng giao diện JavaFX mặc định.
* Không sử dụng quá nhiều border gây rối mắt.

## 11. Implementation Rules

1. Đọc lại toàn bộ code UI-01 trước khi sửa.
2. Giữ nguyên MainWindow architecture nếu không cần thay đổi.
3. Không đưa toàn bộ logic vào MainLayout.
4. Không viết CSS inline trong Java.
5. Không sử dụng dữ liệu database thật.
6. Không tích hợp Monaco.
7. Không triển khai backend.
8. Không thêm thư viện nếu JavaFX đã đáp ứng.
9. Tách các component độc lập.
10. Sau mỗi nhóm chức năng phải build và kiểm tra.
